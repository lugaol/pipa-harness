# Android UI skill
Load when: task involves XML layouts, Compose, Views, theming, UI performance.

- Use `ViewBinding` or `Compose` for type-safe UI.
- Keep `ConstraintLayout` flat; avoid nested weights.
- Support dark mode via theme attributes (`?attr/colorSurface`).
- Use `LayoutInspector` and `Compose Layout Inspector` to debug UI issues.
- Never perform I/O or heavy computation on the main thread.
